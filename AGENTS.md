# Juniper Router agent guide

- Treat GitHub as canonical and fetch before final push.
- The host, not the model, owns permissions, policy, budgets, execution, and
  trusted results.
- Preserve the upstream tokenizer and pin model revisions by immutable hash.
- Keep data, experiments, artifacts, and time records reproducible; retain
  negative results.
- Native Windows CPU is the normative user path. Optional acceleration needs
  named evidence and a CPU fallback.
- Status words are literal: planned, implemented, tested, candidate, approved,
  released, unsupported, and unknown are not interchangeable.
- Never self-approve, merge, or release. A final release requires independent
  Astra and Sol approvals for the same immutable candidate.
